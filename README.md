# Expert Call Analyzer

An AI-powered research tool for analysing expert-call transcripts across the European robotic surgery market.

The application compares expert perspectives, answers predefined interview-guide questions, identifies common themes and differences, and supports natural-language questions across all transcripts. All important AI-generated answers are grounded in the supplied interview data.

## Features

- Reads and parses three timestamped expert-call transcripts
- Answers interview-guide questions for each expert
- Extracts exact supporting quotes with source timestamps
- Identifies common themes across expert interviews
- Highlights differences in expert perspectives
- Supports natural-language questions across the transcripts
- Provides access to the original source transcripts
- Returns an insufficient-evidence response when the transcripts do not support an answer

## Architecture

The application uses a simple grounded analysis pipeline:

1. Transcript files are parsed into timestamped segments with expert, market, speaker and source metadata.
2. Expert-specific interview-guide questions are analysed against the relevant transcript.
3. Backboard is used for grounded LLM analysis and synthesis.
4. Supporting timestamps selected during analysis are mapped back to the original transcript text in Python.
5. Exact quotes are displayed directly from the source transcript rather than generated by the model.
6. Cross-call analysis compares the three interviews to identify shared themes and meaningful differences.
7. Free-form questions are answered only from the supplied transcript evidence.

## Hallucination Reduction

The system is designed to keep generated answers traceable to the source material.

- Prompts restrict the model to supplied transcript evidence.
- Exact quotes are retrieved from the original transcript rather than generated by the LLM.
- Timestamps and source filenames are attached programmatically.
- The model is instructed not to infer unsupported relationships.
- Questions without sufficient transcript evidence return an explicit insufficient-information response.
